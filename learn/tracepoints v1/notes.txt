programs and maps are created using the BPF_PROG_LOAD and BPF_MAP_CREATE commands

the kernel keeps track of the number of references to eBPF programs and maps, releasing them when the reference count drops to zero.

BPF objects can be pinned to a filesystem

BPF links can be used to create additional references

BPF_MAP_UPDATE_ELEM can be used to create entries in a map from user space.

BPF_MAP_LOOKUP_ELEM and BPF_MAP_DELETE_ELEM can be used for retrieving and deleting values from a map.

BPF_MAP_GET_NEXT_KEY for finding the next key that’s present in a map, used for iterating through all the valid entries.

perf_event_open() and ioctl() can be used to attach eBPF programs to kprobe events
